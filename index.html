    BlablaLink 장비 자동 동기화

    기업장비 현황을 계정에서 자동으로 가져옵니다.
    사이트 이용법
    1. Tampermonkey 확장프로그램을 추가합니다 (링크에서 초록색 Get from Store 클릭 후 추가)
    2. 브라우저 오른쪽 위 Tampermonkey를 우클릭 > [확장 관리] > [사용자 스크립트 허용] 체크
    3. NIKKE Gear Manager 동기화 스크립트 설치
    4. 원하는 계정 번호 계정 동기화 버튼 클릭(BlablaLink 로그인 후 다시 동기화 버튼 클릭)
    5. 해당 계정의 장비가 반영되었는지 확인
    6. 실제 인게임에서 기업장비를 아무 니케에게 장착 (미 장착된 기업장비는 확인 불가)
    7. 다시 계정 동기화 실행
    계정 이름 변경은 오른쪽 위 ⚙ 톱니바퀴 아이콘을 눌러 변경 가능합니다.
    비밀번호·쿠키·토큰을 이 사이트에 입력하지 않습니다. 로그인 세션은 BlablaLink 쪽에서 사용되고, 동기화 결과에서 기업장비 타입만 받아옵니다.
    계정이름은 우측 톱니 아이콘을 눌러 변경가능합니다
